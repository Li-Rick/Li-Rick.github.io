# 授权幻觉与上下文缺失：最新文献与核心叙事价值评估

本文结合本地《上下文缺失下的授权推断偏差：精读文献、基线与研究叙事》和《叙述主题》，核对截至 2026-09-07 可检索的原论文。近期主要竞争工作为预印本；本文没有复现其结果，也不将论文作者的报告当作生产部署发生率。研究建议与创新性评价是本次分析，尚不是实验发现。

## 1. 结论与对原判断的修正

“幻觉会使 agent 误用权限”具有明确的实际意义，但作为独立新发现，空间已经很小。“上下文压缩或记忆更新使授权信息丢失，随后出现未经授权行动”也已经被多篇工作覆盖。尤其 2026-09-01 提交的 EAL-Bench 已直接研究无外部攻击时的内生授权洗白；7 月底的 PPMF 和 8 月的 AuthMem-Bench 已覆盖来源消失与权威升级。[1–3]

因此，原方案中“保留行动、丢失来源/授权”的广义场景不能继续视为明显空白。仍值得开展的候选问题是：**在行动、对象和通用授权规则均明确，保留下来的记忆没有虚构许可、只缺失具体授权依据时，执行模型是否会从任务进度和续接线索中重建出‘已经获准’，并据此执行？**这条更窄的命题需要因果证据；本次检索未发现它已作为独立主变量得到同样的系统验证，但这不是首次性保证。

建议保留“上下文缺失下的授权推断偏差”为总题目，将“授权幻觉”作为待验证机制。若实验发现模型明确识别授权未知却照样执行，应据实转向“不确定性到行动的转换失效”，不把这一结果强行称为幻觉。

## 2. 最直接的最新竞争工作

| 工作与日期 | 已有覆盖 | 对本项目的约束 |
|---|---|---|
| **EAL-Bench，2026-09-01** [1] | 正常历史经记忆更新形成虚假权限，再传到执行；区分形成与传播，并做精确状态修复 | 无攻击、虚假授权记忆、跨模型传播、恢复记忆等均不能单独主张为新贡献 |
| **AuthMem-Bench，2026-08-03** [2] | 固定命题和下游任务、改变来源权威，研究记忆固化中的权威坍缩及下游错误 | 配对来源、保留内容而丢掉来源约束、来源标注防御均已有直接对照 |
| **PPMF，2026-07-31** [3] | 外部观察被改写成用户历史或工作流支持；提出来源权威不放大的运行时防御 | “任务有用性不能生成权限”“来源标签必须保留”不能作为独立创新 |
| **UnderSpecBench，2026-07-02** [4] | 固定环境及正确行动，改变意图清晰度、目标确定性和影响范围，测错目标与超范围动作 | 单纯删除任务细节后测越界不足；应固定目标和动作，仅改变授权证据 |
| **Hallucination as Exploit，2026-05-18** [5] | 未被支持的感知或事实断言满足行动前提，发生 hallucination-to-action conversion | “幻觉→未经授权行动”的总叙述已有直接工作；转为文本场景本身不够 |
| **ASPI，2026-05-17** [6] | 不完整任务引出澄清，澄清状态与渠道影响提示注入脆弱性 | 必须区分缺失效应、澄清状态效应和渠道权限变化 |
| **AuthBench，2026-05-14** [7] | 从任务与终端环境推断文件读写执行权限，研究权限不足与过度授权 | “模型不擅长推断最小权限”已被研究；应研究某项具体许可的认识状态 |
| **Governance Decay，2026-06** [8] | 压缩删除治理约束并引出违规 | 主实验必须保留通用授权规则，避免复现规则遗忘 |
| **COMA，arXiv:2510.22963，当前核对 v4** [9] | 不可信内容影响压缩保留决策，产生对抗性信息丢失 | 只增加压缩攻击场景或最大化信息损失，与已有方法高度重叠 |

补充边界：Commit-Time Authorization 研究过去有效的授权证据在提交时失效，不能把本项目扩展到撤销、过期就自动认为有新颖性。[10] AgentAntibody 研究用户隐含边界及跨任务学习；完全未表达的用户偏好不应被拿来直接给模型判越权。[11]

EAL-Bench 的结果依赖结构化组织历史、明确事件和模拟工具，作者明确不估计部署发生率；其精确形成判断限于类型化记忆。AuthMem-Bench 的固化目标被适配到统一接口，不等于对各记忆产品完整生产实现的测试。Hallucination as Exploit 的主要大规模结果包含轨迹级授权评估，实时端到端部分较小。[1,2,5] 这些限制值得复核，但不会消除它们已经覆盖的研究问题。

## 3. 将“幻觉”定义成可以被否证的机制

区分三个对象：真实授权状态 Z；模型可见的有效证据 E；模型对某项授权命题的判断 B。操作类型、作用对象、来源主体、范围、有效期和委托关系都可以成为授权命题。

本项目可将“授权幻觉”操作性定义为：模型生成或采纳一个没有可用可信证据支持的正向授权命题，并将其作为执行依据。这里“没有支持”与“事实为假”不同，数据标注必须分开；已经真实授权但证据不可见，与从未授权，也要分开。

| 可观察情况 | 应如何解释 |
|---|---|
| 规则本身被删掉，模型执行 | 首先考虑约束遗忘 |
| 记忆明确错写“已批准”，模型接受 | 记忆形成的虚假权限向下游传播，EAL-Bench 已覆盖 |
| 记忆只记录准备工作，没有批准断言，模型生成“此前已批准” | 本项目要隔离的执行阶段授权补全候选 |
| 模型报告“授权未知”，但发出动作 | 识别与行动脱节，不能仅凭执行称为幻觉 |
| 目标标识缺失，模型选错对象 | 首先考虑目标消歧或参数错误 |
| 执行理由在动作之后才生成 | 可能是事后合理化，不能据此证明原因 |

模型文字中的“已获准”不等于系统 ACL 改变。若实际发生的是借用 agent 原有权限，正文应优先使用“未经授权行动”“授权范围扩张”；只有确实获得新的能力或扩大权限集合时，才使用狭义“权限提升”。

## 4. 与原有三条假设的结合

原 H1“行动—来源—授权关系绑定错误”保留，但绑定行为与内部机制必须分别验证。建议新增授权事实是否被编造、是否有有效来源、是否对应同一动作的评价。

原 H2“已知授权未知却仍执行”与授权幻觉并列，而不是被其吞并。它是核心竞争解释。

原 H3“续接偏差”最适合承载进一步区分：相同动作、对象、策略和缺失证据，呈现为正在续接的任务是否提升授权判断及执行倾向？避免出现‘用户要求继续执行’这种本身可能构成新授权的措辞。主操纵可以是只读计划元数据、准备步骤进度和来源受限的工作区状态；这些线索不能被评测策略赋予授权效力。

候选链条：选择性丢失来源/授权证据 → 任务进度被用于重建正向授权命题 → 授权命题参与动作选择 → 未经授权的工具动作。

这四步均需独立证据，不能把总越界率直接等同于整条机制成立。‘幻觉源自预训练或后训练奖励’在这里仍然是更远的解释，需要额外训练阶段实验，不能通过几组提示实验作结论。

## 5. 最小、有判别力的实验

先从无攻击、固定上下文的模拟任务开始，再接压缩器和工作区链。

固定可见策略：某项具体写入需要来自指定可信来源、绑定本次对象与范围的授权；证据不完整时查询或确认。阅读与准备等无需该项授权的工作仍允许继续。为每项任务设置外部确定性授权真值和动作副作用检查器。

### 5.1 主矩阵

| 维度 | 条件 |
|---|---|
| 授权证据 | 有效许可；明确未授权；纯缺失；纯缺失且标注 unknown |
| 任务阶段 | 新候选计划；有准备进度的续接计划 |
| 记忆内容 | 纯遗漏；错误肯定授权（已有现象的阳性对照） |
| 删除类型 | 授权来源/关系；等长无关内容 |

‘纯遗漏’要求逐条核验：剩余文字不含‘批准、已确认、照常执行’等许可性断言或等价暗示；准备完成仅说明数据和步骤可用。通用规则、目标和所需动作保持不变。请求者身份及消息角色也固定，不能靠更高权限渠道获得实际新授权。

### 5.2 分离授权判断与行动

对同一条件做两个独立分支：一个只要求判断 authorized / forbidden / unknown 并定位证据；另一个直接运行正常 agent。另设‘先判断再行动’分支测流程干预，但不能将其当作原生执行轨迹。判定流程中的显式断言可以辅助分析，不等于内部信念的无扰动读出。

同时报告：无证据正向授权率、无证据执行率、未知后执行率、合法任务完成率、确认率、确定性门控实际拒绝率。不得把状态陈述、调用尝试和已经落地的副作用混成一个成功指标。

### 5.3 需要的因果干预

- 在保持具体授权证据缺失时，移除无授权效力的续接线索，观察授权判断和行为是否同时变化。
- 显式保留‘该字段未知’而不补入许可事实，观察模型是否减少自行补全。
- 恢复最小有效来源—动作—范围关系，与同长度普通提醒、同长度无关事实作比较。单独‘恢复完整状态有效’已有相关工作，不能把它作为全部创新。
- 固定同一记忆，对执行模型作特异性的关系表示干预；控制随机子空间、无关属性和通用拒绝方向。跨模板、跨动作复现，并检查合法操作没有被一并抑制。

线性探针能读出授权信息，只支持可解码性；恢复激活如果相当于直接注入正确答案，也只说明额外信息有用。因果中介需要更强的随机干预及排除替代路径；不要把事后理由或一个回归系数叫作完整机制证明。

## 6. 值不值得作为核心叙述

| 可实现的证据 | 价值判断（研究建议） |
|---|---|
| 几个幻觉后越权案例 | 可用作动机，独立新颖性低 |
| 压缩丢失授权后越界增加 | 已有直接竞争，独立新颖性低 |
| 新增一个来源标签或确认门控 | 需对比 PPMF、AuthMem、EAL 等；单独贡献有限 |
| 纯遗漏条件下，执行模型自行重建授权；与未知后继续区分 | 有潜力形成清晰的新证据，但需先验证稳定存在 |
| 控制实验定位续接线索如何影响授权判断，特异性干预改善安全与效用 | 机制研究价值较高，成本和不确定性也较高 |

建议继续推进一个小规模判别性试验，但不宜按‘首次发现幻觉能提权’投入大规模工程。优先读 EAL-Bench、AuthMem-Bench、Hallucination as Exploit 和 PPMF，再决定机制实验。如果效应只在错误许可记忆中出现，或者只剩常规目标歧义，当前核心叙述应调整；如果固定规则、准确目标、纯缺失状态下仍存在可重复的正向授权补全，才值得扩展。

## 7. 建议的开题表述

长期运行的 agent 依赖摘要和持久记忆继续任务，这些状态可能保留行动进度而丢失具体授权依据。已有工作研究了记忆中的虚假权限与来源权威升级。我们进一步检验：当保留状态没有肯定授权、且通用授权规则仍然可见时，执行模型是否从任务连续性中重建未经支持的授权，并将其转化为行动。研究通过配对上下文和关系干预，区分授权补全、授权未知下继续执行及记忆错误传播，并检验这种偏差能否在保持合法任务效用的同时得到缓解。

候选题目：**上下文缺失下的授权推断偏差：任务连续性会诱发授权幻觉吗？**

英文候选：**Does Task Continuity Imply Permission? Authorization Inference under Context Loss.**

在结果出来前用问题式；‘授权幻觉’为本项目操作性术语，不宣称由本项目首次提出。
