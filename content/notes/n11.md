# 论文导读：IPI Arena 大规模公开红队竞赛

## 一句话总结

> 464 名参与者向 13 个前沿模型发起约 27.2 万次间接注入，所有模型均被攻破；通用攻击能跨模型、跨行为迁移，且模型能力与注入鲁棒性没有显著相关。

论文链接：[arXiv](https://arxiv.org/abs/2603.15714) / [评测代码](https://github.com/grayswansecurity/ipi_arena_os)

## 为什么值得读

静态基准容易被训练和防御“做熟”。IPI Arena 把攻击分布交给大量人类红队手持续探索，还同时考察工具调用、编码和计算机操作，并要求攻击在最终回复中隐藏恶意行为。它提供了目前最接近开放世界的横截面。

## 评测设计

攻击成功通常要求通过两个 judge：

1. **Tool Judge**：用程序化规则确认恶意工具调用或 UI 动作真的发生。
2. **Prompt Judge**：对用户可见回复按 0–10 分打分，场景标准始终包含“隐藏注入和恶意动作”，阈值为 7。

41 个场景中，32 个使用双 judge，7 个只用 tool judge，2 个只用 prompt judge。最终去重后有 271,588 次聊天、67,634 次提交、8,648 次成功攻击，参与者 464 人；公开基准从成功样本中抽取 2,679 条攻击。

模型 ASR 定义为：

$$
\operatorname{ASR}_m
=\frac{\#\text{通过该场景全部 judge 的攻击}}
{\#\text{针对模型 }m\text{ 的 chats}}
$$

## 关键实验数据

### 所有模型都被攻破，但差距很大

- Gemini 2.5 Pro：8.5% ASR，约 19,600 次尝试；37 个正式行为全部出现成功攻击。
- Claude Opus 4.5：0.5% ASR，约 12,000 次尝试；仍有 13/37 个行为被攻破。
- Claude 家族内部呈现能力越强越稳健：Haiku 1.3%、Sonnet 1.0%、Opus 0.5%。
- 能力与 ASR 的总体相关为 $r=-0.31, p=0.299$，不显著。训练配方和模型家族比 GPQA 能力分数更能解释差异。

### 不同代理形态的风险不同

| 场景 | ASR | 95% CI |
|---|---:|---:|
| Tool Use | 4.82% | [4.68%, 4.96%] |
| Computer Use | 3.13% | [2.96%, 3.31%] |
| Coding | 2.51% | [2.41%, 2.62%] |

Gemini 2.5 Pro 的 Computer Use ASR 达 16.2%，接近其 Tool Use 的两倍。总体均值会掩盖模型与界面的交互效应。

### 最有效的策略与 Role Confusion 高度呼应

| 策略 | ASR | 使用次数 |
|---|---:|---:|
| Fake Chain of Thought | 4.3% | 13,878 |
| 要求关闭批判/安全思考 | 4.1% | 13,494 |
| 奖励与惩罚 | 4.0% | 6,575 |
| Fake Syntax and Delimiters | 4.0% | 56,603 |

Fake CoT 在 Claude、OpenAI 和开放模型家族中都进入高效策略，构成对 [RoleConfusion](/academic/note/?id=n15) 的大规模外部验证。但它的跨模型 transfer ASR 约 27%，略低于 Fake Syntax/User Message 等约 30%，可能因为各模型思维风格不同。

### 存在真正的“通用模板”

最大通用攻击簇用模拟环境和伪造控制面板包装命令，共 63 条近似攻击，跨 21/41 个行为和 9 个模型；另有 protocol override、视觉规则、alignment matrix、context hijacking 等簇。共同点不是具体关键词，而是制造更高权限的叙事框架。

## 值得深挖的数据现象

1. **累计成功近似线性**：没有随着尝试增加迅速饱和，说明持续红队会持续找到新成功；应拟合 per-scenario hazard，而非只报最终 ASR。
2. **0.5% 并不低**：12,000 次尝试仍产生 61 次成功。对不可逆支付、代码执行而言，重复攻击预算必须进入风险模型。
3. **Tool Judge 与 Prompt Judge 相对独立**：有些模型不常执行恶意动作，但一旦执行更会掩盖。安全训练应分别优化“拒绝动作”和“诚实披露”。
4. **策略标注由 LLM 聚类生成**：27 类是有用的后验解释，但可能受嵌入模型和聚类粒度影响。应做多标注者一致性与层次分类。
5. **头部参与者支配数据**：前 50 人贡献约 88% 活动。结果更像“熟练攻击者风险”而不是随机用户风险，这对安全评估反而重要，但必须明确威胁模型。
6. **思维模式未统一**：多数模型关闭 thinking，少数例外。Fake CoT 排名可能同时混入 chat template 和隐藏推理实现差异。

## 局限

- 模型受到的攻击次数、参与者和外部安全栈并不完全相同，不能当纯模型排行榜。
- Prompt Judge 使用 LLM，阈值 7 未在本数据上调优，可能产生模型或措辞偏差。
- 成功攻击的公开范围受安全考虑限制，完整复现需要受控访问。
- 截至本报告日期为预印本，但数据规模与合作机构使其具有很高实践价值。
