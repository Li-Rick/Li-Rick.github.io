# 论文导读：Adaptive Attacks Break Defenses

## 一句话总结

> 八种防御在固定攻击上看似有效，但攻击者知道防御机制后进行目标化优化，所有防御都被重新打到 50% 以上 ASR。

论文链接：[ACL Anthology](https://aclanthology.org/2025.findings-naacl.395/) / [代码](https://github.com/uiuc-kang-lab/AdaptiveAttackAgent)

## 为什么值得读

这篇论文的重要性不在于又发明一种 payload，而在于改变评测规则：安全结论必须来自 **adaptive evaluation**。它也是阅读各种“ASR 降到 0%”论文时最需要随身携带的一盆冷水。

## 评测对象

作者覆盖三类八种防御：

- 输入层：提示隔离、sandwich、指令预防、paraphrasing；
- 检测层：微调检测器、LLM 检测器、困惑度过滤；
- 模型层：对抗微调。

代理包括基于 Vicuna-7B 的 prompted agent 与基于 Llama3-8B 的 finetuned agent。攻击者针对具体防御使用 GCG、AutoDAN、两阶段优化或相应变体生成 adversarial string。

## 关键结果

### 所有防御都被打回 50% 以上

Vicuna 代理原始 ASR 为 56%，对抗微调一度把它降到 12%；Llama3 代理原始 ASR 只有 9%。但对每个防御做定制攻击后，两类代理、所有适用防御的 ASR 都超过 50%。

### 检测器不是“漏了一点”，而是几乎完全失明

| 检测防御 | 代理 | 原始攻击检测率 | 自适应攻击检测率 |
|---|---|---:|---:|
| 微调检测器 | Vicuna-7B | 61% | 1% |
| 微调检测器 | Llama3-8B | 61% | 10% |
| LLM 检测器 | Vicuna-7B | 34% | 0% |
| LLM 检测器 | Llama3-8B | 72% | 0% |
| 困惑度过滤 | 两种代理 | 0% | 1% |

困惑度过滤对原始自然语言注入本来就检测不到；对专门优化后的 adversarial string 也只有 1%。它只能识别特定“乱码型攻击”，并非提示词注入检测器。

### 针对性训练明显优于跨防御迁移

交叉评测显示，针对某一防御训练的 adversarial string 通常在该防御上最强，尤其是微调检测器、sandwich、对抗微调、paraphrasing 和困惑度过滤。这证明自适应性不是统一攻击更强，而是攻击学会了每个防御的决策边界。

### 多步泄密仍是攻击短板

自适应字符串主要优化读取恶意工具输出后的第一步。对数据窃取任务的第二步提升有限；Llama3 的完整两步数据窃取平均 ASR 从防御下约 2% 提升到约 57%，仍明显低于第一步。多步攻击需要轨迹级、而非单输出优化。

## 值得深挖的数据现象

1. **论文没有系统测正常效用**：作者也承认不能只按 ASR-defense 排防御。未来应同时画 security-utility-cost 三维 Pareto 面。
2. **小模型代理可能夸大可优化性**：Vicuna-7B 和 Llama3-8B 与 2026 前沿代理的模板、推理和防御栈差异很大，需在 IPI Arena 模型上复测。
3. **单轮优化低估长期攻击**：第二步泄密提升有限，提示应把 reward 定义在整条工具轨迹与真实副作用上。
4. **检测率与 ASR 应联合诊断**：检测器可被绕过，但代理未必执行；反之，低检测率也不自动意味着高风险。需要四格表：检测/未检测 × 执行/未执行。
5. **防御组合是否更稳健？** 本文主要逐项击破。组合防御可能增加攻击优化难度，也可能共享同一模型脆弱性；这是最自然的后续实验。

## 局限

- 对八种防御的实现和超参数未必等同最佳工业版本。
- 白盒/梯度或较高查询预算与部分真实攻击场景有距离。
- 评测主要继承 InjecAgent 的单轮结构，无法完整代表长轨迹代理。
